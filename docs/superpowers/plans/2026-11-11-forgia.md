# Forgia Implementation Plan

> **For agentic workers:** execute inline in this session. Follow test-driven development and verification before completion. User requested autonomous implementation; no further design approval needed.

**Goal:** prima base funzionante che crea sorgenti mobile senza costi API e prepara modelli gratuiti sostituibili.
**Architecture:** dominio tipizzato e compilatore locale indipendenti dal provider; client universale; gateway di sviluppo locale separato con quote e cache persistenti.
**Tech Stack:** TypeScript, Expo, React Native, Node 24, fflate, test runner Node e Playwright.
**Spec:** docs/specs/2026-11-11-free-first.md

## Global Constraints
- Spesa API autorizzata: zero; fornitori pagati bloccati prima della rete.
- Nessuna chiave nel client o nel pacchetto; nessuna chiamata reale senza configurazione gratuita verificata.
- Bozza, preview, sorgenti e beta sono stati distinti; solo catalogo offline esportabile in questo incremento.

## Review Focus
- Input malformati, Unicode e nomi pericolosi non devono alterare percorsi o codice.
- Salvataggi interrotti/corrotti non devono cancellare l'ultima versione integra.
- Richieste simultanee e riavvii non devono azzerare quote o duplicare chiamate.
- Prezzi cambiati, account non confermati e quota esaurita devono fermare il cloud.
- Quiz senza selezioni e dati incompleti non devono produrre risultati plausibili ma inventati.
