# Erbario di Gian

Sorgenti generati da Forgia tramite modello di catalogo offline. Non è una beta firmata o collaudata su dispositivo. Nessuna AI o API necessaria in questa app generata.

1. npm install
2. npx expo install --check
3. npm run check
4. npm start

Prima della distribuzione impostare identificativi univoci, creare un lockfile con le dipendenze verificate, compilare e provare installazione pulita, salvataggi, rete assente e accessibilità su iOS e Android. I dati locali si perdono disinstallando l'app. Il quiz riguarda solo i colori forniti. Le risposte del ripasso sostituiscono l'ultimo risultato; non modificano i dati del catalogo.
